# 首次配置

1. 登录 `https://你的域名/admin`。
2. 填写 Telegram Bot Token 与小程序 HTTPS 公网地址。
3. 填写源 115 CK，或给每个监听目录配置独立 CK。
4. 新建监听目录并从 115 网盘选择源目录，自动生成 CID。
5. 使用 CD2 时配置主机、gRPC 端口、Token、API 根目录和容器挂载根目录。
6. 可启用 CD2 元数据旁路，减少源账号 115 目录 API 请求；CD2 故障会自动回退。
7. 生成月度、季度或年度绑定码，让用户在 Bot 中绑定会员。
8. 确认历史基线、稳定等待和自动删除规则后，再启动自动扫描与派送。

## 推荐参数

- 115 API 最小间隔：5 秒
- CD2 API 最小间隔：5 秒
- 秒传任务最小间隔：5 秒
- 单任务超时：30 秒
- 监听轮询：60 秒
- 文件稳定等待：至少 30 秒

## CD2 路径示例

- 容器挂载根：`/cd2/miaochuang`
- CD2 API 根：`/miaochuang`
- 监听挂载路径：`/cd2/miaochuang/剧迷Gimy/派送目录`
- 自动映射后的 API 路径：`/miaochuang/剧迷Gimy/派送目录`
