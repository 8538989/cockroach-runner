# 故障排查

## 容器反复退出

运行 `docker compose logs --tail=200`。常见原因：激活码缺失或错误、Fernet 密钥格式错误、端口占用、数据目录权限错误。

## 小程序 502

先检查容器 `/healthz`，再检查反向代理上游是否指向正确端口。Cloudflare 正常而 Host Error 通常表示源站或反向代理不可达。

## Bot 409 Conflict

同一个 Bot Token 被两个实例同时执行长轮询。停止旧容器、DIAN115 Bot 或其他重复实例，只保留一个。

## 新文件没有派送

依次检查：服务总开关、监控心跳、监听源错误、稳定等待、用户会员、CK、非根接收目录、关闭接收/关键词/分类/TMDB 规则和排除词。

## 115 Errno 61、405 或超时

这是115接口拒绝或风控。项目会退避重试、尝试成功账号接力，并可使用 CD2 元数据旁路减少源端查询。CD2不能替代最终目标账号的115秒传。

## 分类目录没有创建

确认用户主动开启了“按分类建立落盘目录”。该选项默认关闭；开启后会在下一次匹配派送前自动创建目录。
