# 小程序与接收规则

小程序源码已经合并在 `companion/static/`，随 Docker 镜像一起发布，无需单独构建或部署。

## 用户必须完成

1. 使用会员绑定码绑定 Telegram 账号。
2. 手工填写 CK 或选择115登录端扫码获取 CK。
3. 从115网盘选择一个非根目录作为接收文件夹。
4. 保存账号与接收目录。

CK 或非根接收目录缺少任意一项时，服务不会为该用户创建派送任务。

## 接收模式

- 全部接收
- 按订阅关键词
- 按分类
- 订阅关键词和分类同时满足
- TMDB 精确订阅
- 关闭接收

排除词对所有开启的模式生效。保存新规则后，尚未开始且不再匹配的等待/重试任务会自动取消，运行中和已完成任务不会被破坏。

## 分类层级目录

“按分类建立落盘目录”默认关闭。用户主动开启后，服务会在已选择的接收目录下自动查找或创建 `电影`、`剧集`、`动漫`、`纪录片` 或 `其他` 子目录。不开启时直接落盘到用户选择的目录，适合交给 MoviePilot 等整理工具继续处理。
